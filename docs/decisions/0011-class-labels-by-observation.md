# 0011 分類の呼び名を、モデルが確認した事実にする

状態: **承認（2026-11-26。写真で確かめた結果を示したうえで、呼び名の案にユーザーが「y」、直した実画面に「OK」）**。[ADR 0010](0010-candidate-wording-and-count-card.md) の分類の呼び名と件数のカードの一部を改める。

## 背景

- 実データの判定保留 10 件のうち 9 件は、タイルの縁に接することが理由（`reason: "edge"`）だった。カードの「新規か既存かを、写真から判断できませんでした」は、この 9 件に合わなかった（ユーザー指摘「保留の意味がわからない」）。
- 次の目視は、解像度の低い写真（1 画素が約 0.5 m）を Claude が見た判断で、正解データとの照合でも、独立の確認でもない。
  - **縁の決まりを外すと分類が変わる 8 件**: 「新規出現」になる 3 件は、川と鉄橋・何もない地面・車で、建物に見えない。「描き漏れ」になる 5 件は、3 件が両年に建物、1 件は輪郭が駐車場や道路まで広がる、1 件は切れ端で判断できない。
  - **もとの「新規出現」7 件**: 新しく建ったように見える 2、新しい屋根はあるが建物か不明 1、判断できない 1、**2018 年の写真にも同じ屋根がある 3**。
- 評価の診断（`eval.json` の `existing_absent_in_2018`）では、建物データにもある評価対象の 200 棟のうち 66 棟（33%）が、「2018 年の抽出が何も見ていない」の条件に当たる。「新規出現」は新しく建ったという意味にならない。原因が 2018 年の写真の暗さかは、確かめていない。

## 決定

| 分類のキー | 理由 | 呼び名（旧） | 呼び名 |
|---|---|---|---|
| `confirmed_new` | `new_absent_2018` | 新規出現 | 2018 年は未検出 |
| `existing_omission` | `present_2018` | 既存の描き漏れ | 2018 年も検出 |
| `uncertain` | `edge` | 判定保留 | 端のため未判定 |
| `uncertain` | `ambiguous` | 判定保留 | 要確認 |

- **分類のキー・分類の決まり（縁の決まりを含む）・DB は変えない。** 「候補」が全分類の全体であること（ADR 0010）も変えず、どれも隠さない。
- まとめて数える所（地図の切り替え・グラフ・比較）は「**未判定**」の 1 つ。表の行・地図の印の名前・詳細・件数の内訳は、理由の呼び名。
- **API**: 地図用データの properties に `reason`。件数の結果に `held`（未判定を数えて 1 件以上のとき。理由の合計が未判定の件数と合わないときは付けない）。
- **件数のカード**: 表を出せるときは、枠・画面の見出し（読み上げには残す）・全体の数や内訳の行・説明の行を出さない（件数は返答の本文が言う）。表を出せないとき（0 件・行数が合わない・別の解析結果）は、見出しと数を残す。表は、2018 年は未検出 → 要確認 → 端のため未判定 → 2018 年も検出の順（同じ中は面積の大きい順）。ボタンは「全 N 件を表示」。
- **候補の一覧**も、カードの枠を外す（並びは面積の大きい順のまま）。比較・地図・精度などの回答の枠は変えない。
- **Gemini への指示**: 新しい呼び名を使う。「新規」「新しく建った」と書かない。`held` があれば分けて書く。注意点は「各候補の詳細の写真で確かめる」。
- トップの説明と、取り壊しの質問への断りの「新しく現れた建物」は、「建物データに載っていない建物の候補」にする。

## 見送った案

- **縁の決まりを外す**（実データで新規出現 7→10・描き漏れ 1→6・保留 10→2）: 上の目視で、新規出現に建物でないものが 3 件入る。推論はタイル 1 枚ずつで周りの画像が無いため、縁で誤検出した可能性がある（未検証）。
- **「新規出現」だけを主な一覧にし、描き漏れを外す**: 「新規出現」の中にも誤りがある。
- **面積や確率で除く**: 7 件では線引きできない（3 番目に大きい 75.64 m² も誤り）。

## 影響・未確認

- Python 版との照合（`golden_test.go`）は、凍結した期待値に、文の読み替えを 2 つ足した（質問の例と、取り壊しの断り）。7,810 件の質問で、呼ぶツールと引数は変わらない。
- 保存済みの回答の本文は、旧い呼び名のまま表示される。
- **残る穴**: 返答文が数字の検査で固定の文（「数字はカードに表示された値を見てください」）に替わると、表を出すカードには内訳の数字が無い（全体の数は「全 N 件を表示」か表の行数で分かる）。
- **未確認**: 直した指示での実 Gemini の返答文（実装では呼んでいない）。README のスクリーンショットは旧い呼び名のまま。
- 抽出そのものの改善（2018 年の写真の明るさの補正・隣のタイルもつないだ解析）は、別の作業で、決めていない。
